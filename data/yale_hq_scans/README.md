# Yale high-resolution Voynich scans

This directory contains the 207 JPEG files unpacked from the ten uploaded source archives. There are 206 unique page-image positions; `0023_11r.jpg` is intentionally preserved in both archive 1 and archive 2 because it occurred in both uploads.

Source: Yale University Library, Beinecke MS 408, IIIF manifest `https://collections.library.yale.edu/manifests/2002046`.

Files are grouped by the original archive number: `1`, `2`, `3`, `4`, `5`, `6`, `8`, `9`, `10`, and `11`. See `import_report.json` for the Yale canvas, download URL, byte size, and SHA-256 checksum of every imported file.
